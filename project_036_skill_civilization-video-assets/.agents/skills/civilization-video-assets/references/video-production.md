# 动态提示词与验收

## 段落模板

视频 ID / 最终时长 / 原片策略 / 世界版本 / 角色与物件版本 / 参考图映射。
逐镜写：起止秒、摄影机持有者、景别、主体动作、环境响应、关键证据、首末状态、下镜衔接、台词/环境音/音乐。

提示词骨架：
“使用所附{实体母图与关键帧映射}。这是{当前/档案}的{POV类型}。0–{t1}秒{主体行动与摄影机移动}；{t1}–{t2}秒{证据出现与人物反应}；最后{收束动作}。保持{固定几何、服饰、方位与持物}。声音为{准确文本/情绪/环境}。不要{具体风险}。”

摄影机的运动必须有空间依据：无人机先定位，再下降到需要检查的结构；不要直接跳到不可能的另一侧。固定摄影机由角色摆正时，画面本身应受手触影响，不该多出第二台摄影机。手持POV与无人机第三视角分清主体。

历史档案可以由当时工作人员拍摄，Traveller 在现在评论；不要把两个时空写成同一摄影者。保持剧透顺序，不能在早期镜头提前展示脚本后期才揭示的地下空间。

## 15–20秒策略

默认 15 秒合格完整段即可交付。16–20 秒需有足够自然动作素材。多原片剪辑后最终仍在范围内，清单记录原片时长、剪辑区间和最终实测时长。自然短暂悬停、余韵可以用于收尾，但不能用冻结或黑屏把短缺素材伪装成足长动态。

## 声音与字幕

默认遵循用户脚本声音配置，不自动把历史项目的英语独白、低BGM与固定字号套给所有作品。需要旁白时按实际语速安排，容纳呼吸和停顿，过长则删减或重新安排。
字幕必须对应实际说出的词；若句尾被截断，改用真实音频或在预算内重制，不把未念完的脚本硬烧进片子。ASR可做定位和核对，不能把生成目标、波形或自动转写本身当作完美同步证据。音乐需可用来源，避免抢对白；响度测量按真实声道配置，不将默认单声道合并峰值误判为立体声削波。

## QA

每条检查并记录：
- 文件非空，容器与视频流可读，全片音视频解码完成。
- 实测时长15–20秒、尺寸/帧率符合约定；无音轨时明示silent。
- 每镜首中尾与切点检查主体身份、结构、持物、天气/损伤、空间方向、穿帮、黑帧、异常冻结。
- 全条观看关键动作，静帧抽样不能证明全程无变形。
- 全条试听：词句完整、人物声音符合设定、对白与动作时间关系、BGM与结尾；字幕不过大、不遮证据、无交叠。
- 结尾完整收束；没有截断手部动作或台词，也没有无意义长黑尾。

无法进行某类观察时标 unverified，列出需要用户审看的具体点；禁止写“全部通过”。远程成功但下载损坏，优先重下载同一任务。
