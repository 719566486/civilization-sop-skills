# 无人前文明的创作与可制作标准

## 内部世界完整，当前遗迹具体

详写昔日天文地理、生态、能源食水与废物循环、交通通信、制度阶层、信仰、衣食住行、工艺、建筑、历史与技术边界。它们都属于前文明曾经的生活，不代表现在仍有社会在运作。

每个地区写相对位置、原用途／原使用者、原供给、尺度材料、弃置过程、遗弃时长、现在可见痕迹。时间尺度要吻合：朽烂纤维、盐蚀金属、掩埋街道、失压穹顶与残存机械不能任意组合；解释水、气、泥沙、植被和断电怎样重塑空间。某种储存材料能完好留下，不代表整个房间都保持新净。

视觉必须体现文明独特的功能与文化，同时表现无人遗留状态。亚特兰蒂斯式设定可用潮汐、水压、盐蚀、海洋生态和旧水权分配的物证，不照搬Alpha酸雨风格。不要把所有遗迹都画成同一种断柱神庙；生活、生产、维护与权力差异要能从不同废墟读出。真实历史陈述需查证，原创设定标虚构。

## 观察与证据驱动的探索

每节点：进入／勘察目标 → 环境阻力 → 可执行动作 → 传回证据 → Traveller有限推测 → 玩家可比较的问题 → 下一步。没有当地NPC负责带路、递钥或讲史；钥匙和路线必须由位置、磨损、匹配结构或先前记录被合理找到。

故事三层知识与证据表见 [遗迹与证据契约](ruins-evidence.md)。完整文明复原只在作者内部存在。不要用旁白替玩家解释全部文明，不把一次机关实验成功当作历史动机证实。关键结论有交叉证据，不足处明确保留疑点。

每镜记录node_ref、shot_ref、起止秒、地点／时代、POV、景别、机位运动、Traveller动作、环境动态、entity_refs、keyframe_refs、evidence_refs、首末状态、接镜、声音及剧透限制。尽量用可看见的过程，如“扫去盐壳发现两种不同配额刻痕”，不是“镜头告诉玩家阶级压迫”。每节点15–20秒，复杂取物／插接拆镜。

## 图册的对象与使用边界

全局复用：Traveller、飞行器与已有装备；本文明新增：无人遗迹、关键物件、可阅读的痕迹、壁画／铭刻局部。只有证据需要出现历史人物形象时才建立历史描绘参考，不生成当下文明居民。

地点当前废弃状态为主母图，标明入口、出口、结构、遮挡、光源与探索者尺度；总览应支持定位，不提前揭示玩家尚未取得的全城答案。内部空间图可帮助制作，不等于直接传回游戏。确需昔日复原参考时单列author_only，不能替代当前残迹。

永久层为形体比例、服装遮挡、装备位置、建筑平面与已有损毁；状态层为进一步破损、潮湿、附着物、光态和持物，沿故事连续。每实体保留production_ref、稳定逻辑名、独立rNNN、形体与材料、当前母图、用途、观众范围及关联镜头。图册必须嵌真实图，提示词不能代替图片。
