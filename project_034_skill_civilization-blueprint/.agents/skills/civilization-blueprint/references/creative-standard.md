# 前期创作与可制作标准

## 世界观必须具体到可视化

覆盖：文明主题与独有矛盾；天文地理与路线；气候/生态；能源、食物、水与废物循环；交通/通信；制度、阶层、宗教与价值冲突；普通人的衣食住行；工艺、材料、建筑与装饰语法；重要历史节点及其当下后果；科技或超常机制的能力边界、成本与失效方式；主要地区与群体；Traveller 进入条件、目标、风险与退路。

每个重要地区至少交代：相对位置、用途、居民或使用者、供给来源、尺度、材料、当下状态和可被看见的历史痕迹。每种奇观都应有功能或文化原因。同一个世界不能只有宫殿和遗迹，没有生活与维护系统。

风格板包含主辅色、明暗关系、材料纹理、几何母题、服饰剪裁、摄影与空间尺度。文明特征必须由设计体现：亚特兰蒂斯可以围绕水压、潮汐、盐蚀、海洋生态和水权制度展开；不自动套用 Alpha 的黄棕酸雨和桥墩。涉及真实历史的陈述需查证，原创设定标为虚构演绎。

## 剧情双层结构

作者知道的真相与 Traveller 当时知道的线索分开。每章写：目标 → 行动/阻碍 → 物理证据 → 判断改变 → 代价/下一步。避免靠最后一段旁白解释全部，也避免每章堆一个互不关联的新谜团。

每镜执行表字段：segment_id、shot_id、起止秒、地点/时代、POV持有者、景别/焦距意图、镜头运动、人物动作、环境动态、证据、entity_ids、keyframe_ids、首帧状态、末帧状态、接镜方式、对白/旁白、环境音、音乐意图、负向限制。

镜头提示词必须描述动作过程，而非只有“史诗、电影感、震撼”。例如“镜头沿阀门刻度移动；潮水在门底抽离；Traveller 停手，发现反向磨损”，比“神秘水下神殿”更可执行。不要在一秒内塞入拿起、递出、接过、开启四个动作。

## 母资产与状态

身份永久层：体型、服装结构、面部遮挡、装置位置、载具结构、建筑平面。
状态变化层：潮湿、腐蚀、破损、附着物、灯态、手中物。状态随故事变化，不能随机回到完好。
每个实体记录：ID、版本、叙事用途、形体比例、颜色材料、固定特征、变化范围、需要的视图、已通过母图、关联镜头。

地点设定图不是一张气氛壁纸：必须让后续生成者知道入口、主结构、出口、视线遮挡、光源与人物尺寸。多视图应彼此核对，不能用互相矛盾的俯视图和正视图作为同一基准。

图册示例结构：全局复用区 / 本文明人物 / 本文明物品 / 本文明地点 / 状态与版本表。每项嵌入实际图，并配可复制的短身份描述。提示词放在图片下面，不能占据图片的位置。
