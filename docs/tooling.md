# 工具与历史制作经验

这套流程从三个生产阶段提炼：故事与设定开发、母图与剧情图像生产、Kling短片及声音后期。参考案例包括 Traveller 四条 POV 记录、TX02 无人机检查、Day 3 The Spine、舱内自白和后续预告片。不是将某三个文件夹未经核对地称为全部历史。

## 有历史记录支持

- Codex内置imagegen：POV关键帧、载具扫描关键帧、舱内固定机位。
- Kling：参考图生成动态、原生情绪独白；后期要检查台词实际是否念完。
- general-video / hyperframes：历史规范与预告片工程使用；并非每条短片都由HyperFrames渲染。
- media-use：媒体和声音相关流程记录。hyperframes-core、hyperframes-cli、hyperframes-audio等是框架按需域技能，不将“清单可见”冒称每项都有独立调用记录。
- FFmpeg/ffprobe：混音、字幕、拼接、实际时长与全片解码；Whisper用于对白核对。

## 可选与未证实项

Flova是本次要求新增支持的替代视频路线，不能说旧Traveller案例已由Flova生成。Remotion、ViMax、music、kling-cli等本地包不构成所有片段实际使用证据。

## 可推广的修正

先区分有效稿与历史稿；角色母图、载具结构、场景空间保持一致；每张图承担不同叙事职责；档案摄影者与Traveller当前视角分开；对白以实际音频为准；下载损坏先重新下载原任务；实测视频时长；字幕音乐按新用户需求配置。

不要把旧项目的酸雨废土、特定BGM、英文男声或固定字号写成所有文明的风格。不要把历史模型支持、积分价格和账户余额固化为工具事实。
