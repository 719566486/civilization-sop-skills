# 图像生成模板与检查

## 构建提示词

按顺序组合：
1. 图片用途：身份母图 / 场景建立 / 动作首帧 / 证据特写 / 动作末帧。
2. 文明视觉规则：来自当前 world，而非默认科幻模板。
3. 实体锁定：逐一说明输入参考对应哪个角色/物件/建筑，以及应保留什么。
4. 场景结构与人物尺度：入口、通道、地形、光源、人物位置。
5. 时空状态：当前/档案，衣物湿度、物件持有者、损伤进度。
6. 构图与运动余量：机位、视线、手脚可见程度、视频后续要移动的区域。
7. 限制：针对当前镜头的具体错误，不堆通用负面词。

可复制模板：

“生成 {segment}/{shot} 的 {frame_role}。参考1锁定{entity_ref}的{固定特征}；参考2锁定{location_id}的{空间结构}。当前是{era}，{start_state}。镜头由{camera_owner}持有，位于{position}，朝{direction}。主体{可被执行的姿态}，为随后{action}保留空间。{文明材料/光照}。必须保留{证据}；禁止{本镜风险}。输出{比例}的满幅画面。”

若工具只接受较少参考，选择与当前镜头最相关的母图；不要声称所有参考都已注入。不支持首尾帧的视频后端仍可将末帧用作验收目标，但必须标明没有作为端点控制输入。

## 项目提炼

- 先读取有效版本：旧稿中的时间错位不能混进新版实体坍塌叙事。
- 档案图的颗粒、曝光与划痕可以是媒介风格；未经要求不要生成相纸边框、书页或卡片，避免影响后续图生视频。
- POV 中不要无理由看到正在拍摄的摄影机本体；多出第二台摄影设备属于实质错误。
- 载具近距扫描采用一张明确几何基准，验证喷口数量、翼展与顶部结构不会随镜头改变。
- 摄影方式取决于脚本；旧设备晃动可以有动机，但不应成为全片机械抖动。
- 图像漂亮不代表合格：新文明不能被生成成与世界设定无关的现代公路或泛化废土。

## 验收表

每张记录：身份与比例 / 地点结构 / 状态接续 / 动作首末可达 / 剧情证据 / 风格 / 文件完整性。
截图对照母图与前后帧。静帧没有验证动态、口型、台词或音画同步，禁止扩大检查结论。
