# SOP 2 · 文明图像资产生产

输入 SOP 1 的三份文档、实际设定图和 handoff.json；输出可直接指导视频生成的真实图像。用户要求优先，保持已有有效设定与授权范围。

## 逐步操作手册

执行前读取 [操作手册 v1.1](references/operations-manual.md)。其中逐步列出工具、输入输出格式、参数与提示词、合格标准、失败返工、命名版本和单节点资产清单；本页提供流程入口，具体执行以手册和交接契约配合使用。

## 执行

1. 按 [交接契约](references/handoff-contract.md) 检查版本、图册引用和每镜资产。如果没有 JSON 而三份文档完整，可根据原文补清单；缺少关键设定图时指出具体缺项，不能自行改变人物身份。对不受缺失影响的图像继续准备。
2. 检查生图路线。默认使用宿主已提供的内置 imagegen；指定 Image2 时读取实际安装的工具/技能与帮助，确认服务商、模型、参考编辑能力、输出目录和授权。Image2 是模型称呼而非统一 API；本技能不内置第三方凭据，也不把 Pilio 视为 OpenAI 官方接口。不因失败自动切换服务商。
3. 建立图像生产矩阵：镜头 → 叙事任务 → 实体母图 → 首/中/末状态 → 构图 → 输出。建议每段先做 A 建立、B 动作关系、C 证据/收束三个不同任务的关键帧；数量随动作需要调整，不能机械复制三张同构图图片。
4. 读取 [图像生成与检查](references/image-production.md)。先生成代表性镜头核对文明风格和实体身份，检查合格后批量派生。在连续镜头中附加锁定母图与已合格相邻帧；避免长链反复以漂移图作为唯一参考。
5. 调用真实生图工具。每次提交前记录参考路径及其用途、完整提示词、期望 ID。已有任务未确认失败前不重复提交；下载失败先找原任务，不能靠再生成解决下载损坏。
6. 获取真实文件，检查图像尺寸和像素内容。母图一致性、人物/载具比例、地点拓扑、时间状态、动作可达性、文明特征、关键证据逐项过关。出现局部错误时从合格版本编辑，不无理由重做全组。
7. 保存 `images/`、`image_manifest.json` 和 `qa/image-review.md`；最终使用图与失败图分开。qa 逐项标 passed / failed / unverified，没有看过像素的图不能标视觉通过。
8. 覆盖脚本所有必需 keyframe_id 后交给 SOP 3，同时传递 SOP 1 的脚本、图册和世界规则。汇报生成张数、未覆盖镜头与检查状态，不声称已经生成视频。
